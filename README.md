Game Idea:
Simple Treasure Extraction RPG:
3 classes can enter a dungeon to find treasure and try to extract it to keep the loot.
Can fight monsters in the dungeon and use some of the treasure items to fight.


README POINTS:

A)
- To win the game, you must defeat the hydra, and extremeley difficult boss.
- It is highly recommended to save your heals for this fight!
- Move around with W,A,S,D.
- Press esc to pull up the menu to view your inventory, map, or character stats.
